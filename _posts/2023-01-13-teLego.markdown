Enabling a user to <i>shrink</i> down into their Lego set as one of their Lego models. 
  
Fixing a Raspberry Pi stereo camera module to a Lego Mindstorms robot to be the eyes of the robot, that can be viewed in a VR head-mounted dispay (HMD). The Lego robotic avatar can then be controlled in VR from the perspective of the robot in the Lego set world. The head of the robot will turn with the head of the user/HMD, ideally so will the arms so the participant can interact with the Lego world and build the set from within the set.
